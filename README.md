## 📚 Visão Geral

Repositório de estudos focado no desenvolvimento **backend com Flask**, explorando conceitos fundamentais e avançados para construção de aplicações web robustas.

**Objetivo Principal**: Aprender e praticar tecnologias essenciais para desenvolvimento backend através de exemplos práticos e implementações progressivas.

---

## 🎯 Tecnologias em Estudo

### 🔧 Core Framework
- **Flask** - Microframework web
- **Flask-WTF** - Integração com formulários
- **Flask-SQLAlchemy** - ORM para banco de dados

### 🗄️ Banco de Dados
- **SQLite** - Desenvolvimento e testes
- **SQLAlchemy** - ORM e migrations
- **Modelagem de dados** - Relacionamentos e queries

### 🏗️ Arquitetura
- **Blueprints** - Organização modular
- **Estrutura MVC** - Separação de concerns
- **APIs RESTful** - Design de endpoints
